# Language Identifier
This project identifies the language of a string input.
## Supported Functionality
The following languages are supported in this project:
Albanian, Arabic, Armenian, Azerbaijani, Burmese, Czech, Danish, Dutch, English, 
Estonian, Finnish, French, Georgian, German, Greek, Guarani, Hungarian, Icelandic, Italian, 
Kurmanji Kurdish, Lao, Latvian, Lithuanian, Macedonian, Norwegian, Persian, Polish, Portuguese, 
Romanian, Russian, Serbian, Serbo-Croat, Spanish, Swedish, Thai, Turkish, Ukrainian, Vietnamese  
Entering a language that is not in this list will render results meaningless.
## Input Specifications
Use the console to input a string.

Entering short inputs is likely to result in failure. Use inputs of a few sentences or more for best results.

Each language should be inputted in its standard alphabet. When applicable, optional diacritics should be
excluded.

If possible, exclude foreign accents in foreign words. For example, the English "fiancée" should be written as "fiancee".

Kurmanji Kurdish should be written in the standard alphabet used in Türkiye.

Serbian should be written in Cyrillic script (the Latin script works but is treated distinctly).
